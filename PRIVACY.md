# Privacy Policy for Eonslate

**Last Updated:** 2026-11-13

Eonslate is a personal project built with a privacy-first mindset. This policy explains how the app handles your information.

## No data collection

Eonslate **does not collect, store or transmit** any personal data, tracked entries, financial records, usage statistics or telemetry.

## Offline by design

Eonslate works entirely offline. It does not declare the `android.permission.INTERNET` permission, so it cannot send anything you track over the network.

## Where your data lives

Everything you create is stored in the app's private storage on your device. Backups and exports are written only to a location you choose.

## Permissions

Eonslate asks for a permission only when you turn on a feature that needs it, and explains why first. Each optional permission will be listed here when its feature ships.

## Source code

Eonslate's source code is public, so you can check how it handles your data yourself.
